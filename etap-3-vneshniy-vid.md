## Раздел 1. Система вместо разнобоя

### Темы и палитры

Две независимые настройки:

**Тема** — светлая, тёмная, как в системе. По умолчанию системная: телефон переключается вечером, приложение следует за ним.

**Палитра** — шесть наборов на выбор. Каждый работает в обеих темах.

Настройки независимы: человек выбирает палитру и отдельно решает, светлая она сегодня или тёмная.

#### Как устроено

Тема задаёт `data-theme` на корне, палитра — `data-palette`. Пара определяет набор переменных.

```js
function applyLook(palette, mode) {
  const dark = mode === "dark"
    || (mode === "system" && matchMedia("(prefers-color-scheme: dark)").matches);
  const root = document.documentElement;
  root.dataset.theme = dark ? "dark" : "light";
  root.dataset.palette = palette;   // stone | graphite | smoke | ivory | teal | plum
}
```

При режиме `system` слушать изменения `matchMedia` — переключаться сразу, а не после перезапуска.

Палитры показывать **кружками с настоящим акцентным цветом** в текущей теме — человек сразу видит, что выбирает. Выбранная обведена рамкой. Смена применяется мгновенно, без подтверждения.

#### Что важно проверить

**Шесть палитр в двух темах — двенадцать сочетаний.** Каждое нужно открыть на каждом экране. Это самая трудоёмкая часть работы, и большая её часть — не вставка цветов, а поиск мест, где цвет записан числом мимо переменной.

Обязательно проверить: карточки, поля ввода, выпадающие панели, тосты, состояния нажатия, границы, отключённые элементы, текст на цветном фоне.

**Мелкий текст на приглушённом фоне — главный риск.** В светлых палитрах `--ink-muted` на `--surface-2` легко не дотянуть до читаемости. Если сомневаетесь — темните текст, а не осветляйте фон.

**Экран записи с облаком остаётся тёмным при любой палитре.** Запись голоса — отдельный момент, и облако на светлом фоне читается хуже.

**Виджет живёт по своим правилам.** Системная тема ему не указ: он лежит на обоях, которые могут быть светлыми при тёмной теме. Виджету нужен полупрозрачный фон, работающий на любых обоях.

### Свести тени к трём

Сейчас в `public/styles.css` двенадцать разных `box-shadow`, у каждой свой цвет и размытие. Глаз читает это как небрежность.

Оставить три, задать переменными в `:root`:

```css
--shadow-card: 0 1px 2px rgba(28, 42, 40, .06);
--shadow-float: 0 8px 24px rgba(28, 42, 40, .14);
--shadow-sheet: 0 -8px 32px rgba(28, 42, 40, .12);
```

`card` — карточки записей и настроек. `float` — плавающая кнопка микрофона. `sheet` — выезжающие панели снизу. Больше теней быть не должно. Внутренние обводки (`inset`) заменить на `border: 1px solid var(--line)`.

### Свести скругления к трём

Сейчас используются 3, 8, 9, 10, 12, 14, 16, 18, 99, 999 пикселей и `50%`. Переменная `--radius` есть, но применена только в 13 местах из ста.

```css
--radius-sm: 10px;   /* мелкие элементы: пилюли, теги, поля ввода */
--radius: 14px;      /* карточки, кнопки, панели */
--radius-pill: 999px;/* круглые кнопки, вкладки-пилюли */
```

Пройти по всему файлу и заменить числа на переменные. `50%` оставить только для круглых кнопок.

### Движение

Сейчас на всё приложение восемнадцать переходов. Этого мало: ощущение мягкости даётся именно движением.

```css
--ease: cubic-bezier(.4, 0, .2, 1);
--dur-fast: 120ms;   /* отклик на касание */
--dur: 180ms;        /* появление, смена состояния */
--dur-slow: 260ms;   /* панели, экраны */
```

**Отклик на касание нужен везде, где есть нажатие.** Это самое дешёвое, что делает вещь дорогой:

```css
.card:active, .btn:active, .row:active {
  transform: scale(.985);
  transition: transform var(--dur-fast) var(--ease);
}
```

Отдельно проверить: у кнопок, вкладок, строк настроек, карточек записей и плавающей кнопки отклик должен быть у всех.

## Раздел 2. Иконки

### Убрать неиспользуемые

Восемь иконок в объекте `ICONS` (`public/app.js`) не используются нигде:

```
chat  archive  list  share  chevron  book  bulb  coach
```

`book`, `bulb`, `coach`, `chat` — остатки тренажёра и мастерской. Удалить все восемь, **кроме `chevron`** — его надо, наоборот, вернуть в дело: он нужен на каждой строке настроек (см. раздел 4).

### Набор Tabler

Иконки взяты из открытой библиотеки **Tabler Icons 3.46.0** (лицензия MIT, Copyright © 2020–2026 Paweł Kuna). Файл `lib/icons.js` готов, менять его не нужно — только подключить вместо старого объекта `ICONS`.

Почему готовый набор, а не свои рисунки: профессиональные иконки оптически выверены — толщина воспринимается одинаковой, центры смещены там, где глаз этого требует, пропорции согласованы. Руками это не воспроизводится, а разница чувствуется сразу.

Правила набора:

- сетка `viewBox="0 0 24 24"`
- `stroke-width="2"`, скруглённые концы и стыки
- `fill="none"`, цвет через `currentColor`
- только контурные варианты (`outline`), без заливок

Новые иконки брать с tabler.io/icons, вариант outline, копируя только содержимое тега `<svg>`. **Свои рисунки не подмешивать** — один чужой в ряду ломает ощущение всего набора.

При публикации в RuStore Tabler нужно указать в списке сторонних компонентов.

Сейчас во вкладках полок только текст. Значок рядом с названием узнаётся быстрее слова — особенно на виджете, где мало места.

## Раздел 3. Виджет

Виджет — лицо приложения. Сейчас в пустом состоянии он занимает половину экрана ради серой надписи «Пока пусто».

### Пустой день не значит пустой виджет

Если на сегодня записей нет — показывать **ближайшее из будущего**:

```
СЕГОДНЯ СВОБОДНО

Дальше
завтра 10:00
Встреча с врачом
Таганка
```

Виджет никогда не пустует, и в этом появляется смысл: он всегда что-то знает.

Если записей нет вообще — короткая строка вроде «Скажите, что напомнить» и всё. Не растягивать на пол-экрана.

### Как рисовать список

- **время слева колонкой**, фиксированной ширины, акцентным цветом
- заголовок и место — справа, заголовок 14sp, место 12sp приглушённым
- дело без времени — прочерк вместо часов
- выполненное — приглушить прозрачностью и зачеркнуть
- **никаких рамок и карточек внутри карточки** — только воздух и выравнивание
- сверху строка с датой и числом дел, мелко и приглушённо

Помнить про ограничения `RemoteViews`: произвольного CSS нет, анимации нет. Красота делается типографикой, воздухом и выравниванием.

## Раздел 4. Экраны

### Главный экран

**Одна плавающая кнопка вместо двух.** Сейчас круглая белая «+» и круглая зелёная «микрофон» стоят друг над другом и спорят весом. Оставить только микрофон, ручной ввод повесить на долгое нажатие. Рядом мелкая подсказка «удержать — ввод текстом».

**Кнопка не должна закрывать содержимое.** Сейчас она лежит поверх карточек: на экранах «Витамины» и «Косметика» перекрывает записи. Добавить нижний отступ списка, равный высоте кнопки плюс 24 пикселя.

**Даты без рамок.** Сейчас каждая дата в белой карточке с обводкой — полоса выглядит тяжело. Активная дата — светло-зелёная пилюля (`--accent-soft` + `--accent`), остальные просто текст приглушённым цветом.

**Строка наблюдения** — над списком, 13sp, `--muted`, без карточки и без иконки. Её должно быть легко пропустить.

**Время слева колонкой**, как в виджете. Одинаковый приём в двух местах — это и есть система.

Крайние в кружках, средний голый. Толщина рамки та же, что у карточек — набор остаётся единым.

### Полоса полок под шапкой

**Заменяет экран «Ежедневные дела».** Сейчас туда свалены косметика, спорт, витамины, будильник и дни рождения — их объединяет только то, что они повторяются. Это логика разработчика, а не человека: поставил будильник, а увидеть его негде.

Полоса идёт **отдельным ярусом под шапкой**, не внутри неё. В шапке остаётся три значка — девять там не поместятся и вернут ощущение сложного приложения.

```
├────────────────────────────────────────┤
│  (🔔 07:00)  (👛 2)  (🧴)  (💊)  …    │
└────────────────────────────────────────┘
   заполненные — пилюли accent-soft, значок 16dp + время/счётчик 12sp
   пустые — те же размер и место, приглушённые (контур, ink-muted)
```

**Показывать все полки всегда, в фиксированном порядке.** Пустые не прячутся и не уезжают: состав полосы не меняется при новых записях, можно нажимать не глядя. Заполненные подсвечены и показывают время или счётчик; пустые — приглушены, на том же месте.

**Значок показывает, что именно там:** у будильника время, у платежей число. Один взгляд — и понятно, не надо заходить.

Оформление активной пилюли совпадает с подпиской и активной датой — единый язык: «здесь что-то есть, сюда можно нажать».

**Сейчас его не видно на главном экране** — он спрятан во вкладке ежедневных дел. Человек ставит будильник и не находит его.

Будильник на завтра в семь — это дело завтрашнего дня. Показывать в общем списке наравне с остальным: время слева колонкой, колокольчик справа вместо кружка выполнения.

### Карточка записи

Показывать только заполненные поля, каждое со своей иконкой: время, место, участник, телефон, подробности. Пустые не рисовать — иначе «купить хлеб» будет выглядеть как договор.

### Настройки

**Строки с тонкими разделителями вместо отдельных карточек.** Сейчас каждая настройка — своя карточка с рамкой и тенью, экран выглядит как склад коробок. Сгруппировать по разделам, внутри раздела строки разделять `1px solid var(--line)`, скруглять только внешние углы группы.

**Убрать форму блокировки с главного экрана настроек.** Сейчас посреди аккуратных карточек стоит голое поле ввода «ID человека» и кнопка «Заблокировать» — как техническая панель. Ею пользуются раз в год. Заменить строкой «Заблокированные» с шевроном, форму перенести внутрь.

## Раздел 5. Облако частиц на экране записи

**Делать последним.** Это украшение: оно не заставит человека остаться, если напоминание не пришло вовремя.

### Код готов

Файл `lib/cloud.js` написан и проверен. Менять его не нужно — только подключить.

```js
import { createCloud, listenLevel } from "../lib/cloud.js";

const cloud = createCloud(canvasElement);

cloud.setMode("listening");          // покой → слушает
const stop = listenLevel(stream, v => cloud.setLevel(v));   // громкость с микрофона

cloud.showShape("check");            // собрать фигуру
cloud.clearShape();                  // вернуться к облаку

stop();                              // при уходе с экрана — обязательно оба
cloud.destroy();
```

**`destroy()` вызывать обязательно** при уходе с экрана, иначе кадры считаются вечно и телефон греется в фоне.

### Что это

Экран записи голосом показывает облако из ~1200 частиц на тёмном фоне. Частицы живут по формуле, а не расставлены руками — поэтому их может быть сколько угодно.

Реализация: `<canvas>` с `requestAnimationFrame`. Только на экране записи — на кнопке и виджете это физически не поместится и там не нужно.

### Состояния

| Состояние | Поведение |
|---|---|
| Покой | облако едва дышит, медленно, почти незаметно |
| Слушает | **амплитуда привязана к громкости микрофона** — говорит громче, облако шире |
| Услышала | сжимается в точку, ~400 мс |
| Готово | расходится наружу и гаснет |

Привязка к громкости — самое важное. Именно она создаёт ощущение, что человека слышат; без неё это просто заставка.

### Формы

**Готовится замена.** Владелец генерирует набор монохромных лиц одного персонажа — по несколько вариантов на каждое выражение. Когда они будут готовы, нынешние фигуры (галочка, часы, знак вопроса, улыбка, сердце, солнце, луна, восклицательный знак, точки, ладони) уходят целиком: останется один набор в одном стиле.

До тех пор работают нынешние. Требования к ним — ниже.

Частицы могут складываться в фигуры. Форма рисуется на невидимом холсте, из неё берутся точки, каждая частица получает свою цель и плывёт к ней, продолжая чуть подрагивать на месте.

| Форма | Когда | В спокойном режиме |
|---|---|---|
| Галочка | записала, дело закрыто | можно |
| Часы | напоминание поставлено | можно |
| Знак вопроса | не расслышала | можно |
| Улыбка | хороший день, много дел закрыто | **нет** |

**Улыбка на записи «завтра похороны бабушки в 11» недопустима.** Использовать ту же проверку, что и для реплик — `isHeavy()` из `lib/voice.js`. Одна функция управляет и текстом, и анимацией.

### Запасной режим уже внутри

1200 частиц на дешёвом Android греют телефон. В `cloud.js` это учтено:

- число частиц выбирается по `navigator.hardwareConcurrency`: 400 на слабых, 800 на средних, 1200 на быстрых
- если кадры проседают дольше секунды, модуль сам переходит в простой режим

Остаётся добавить в настройки переключатель «Простой режим» и вызывать `cloud.setSimple(true)`.

## Что НЕ делаем

- Не меняем палитру.
- Не переименовываем приложение.
- Не рисуем лицо из частиц. Абстрактное облако подходит обеим персонам, не отталкивает и не обещает того, чего нет.
- Не выносим облако на кнопку и виджет.
- Не трогаем защиты предыдущих этапов: `verifyPurchaseWithStore`, `revealShelvesFor`, `daytimeAnswer`, `clientIp`, `TASK_VERB_RE`, обработчики ошибок, проверку `decodeURIComponent`, нативные будильники.
- Не трогаем реплики в `lib/voice.js`, иконки в `lib/icons.js` и физику в `lib/cloud.js`.
