# Idea Engine × допил до идеала: VoiceCapture (виджет → голос → задачи)

**Статус:** рабочая идея к проработке (после прогона).  
**Вход пользователя:** CaptureDone + виджет с одной кнопкой: голосовые заметки/встречи → ИИ раскладывает по задачам и ставит уведомления.  
**Цель прогона:** убрать лишнее, найти упущенное, зафиксировать минимальный идеал.

Алгоритм: Генератор (3 заточки одной идеи) → Декомп. → Критик → Судья → Банк → Зеркало.

---

## Ступень 1 — Генератор: 3 заточки одного ядра

Ядро (Слой 3): **снять с головы обязанность помнить** — одним жестом с телефона.

### A — «Только голос, только виджет» (минимализм)

| Поле | Содержание |
|------|------------|
| **title** | VoiceCapture — одна кнопка на экране |
| **layer1** | Жмут виджет → говорят → кладут телефон |
| **layer2** | Некогда открывать приложения и раскладывать задачи |
| **layer3** | Память и дисциплина делегированы жесту + ИИ |
| **inversion** | Таск-менеджеры просят структуру → мы просим только голос |
| **recombination** | Рация × секретарь × системные Reminder/Calendar |
| **mechanism** | Виджет = Hold to talk. ИИ → 1+ задач с датой/временем → системные уведомления. Ничего больше в MVP |
| **timeToMarket** | 3–6 недель (нужен native/PWA+виджет или обход через Shortcuts) |
| **capitalRequired** | низкий–средний |

### B — «Голос + вечерний разбор» (контроль качества)

| Поле | Содержание |
|------|------------|
| **title** | VoiceCapture + Inbox Zero вечером |
| **layer1** | Днём только захват; вечером 2 минуты подтвердить |
| **layer2** | Страх, что ИИ криво распарсил встречу |
| **layer3** | Доверять системе, но раз в день глянуть глазами |
| **inversion** | Автопилот 100% → автопилот + короткий human checkpoint |
| **recombination** | A × авиационный чеклист «подтверди рейс» |
| **mechanism** | Как A + пуш в 20:00: «3 новых: ок / поправить / удалить» |
| **timeToMarket** | +1 неделя к A |
| **capitalRequired** | низкий–средний |

### C — «Мультивход» (голос + фото + share)

| Поле | Содержание |
|------|------------|
| **title** | CaptureDone полный |
| **layer1** | Голос, фото, шаринг — всё в одну воронку |
| **layer2** | «А вдруг сфоткаю чек» |
| **layer3** | Универсальный сейф головы |
| **inversion** | — |
| **recombination** | A × камера × share sheet |
| **mechanism** | Три входа, один движок разбора |
| **timeToMarket** | дольше |
| **capitalRequired** | выше (OCR + больше кейсов) |

**Генератор сразу режет C из идеала MVP:** фото/share — фаза 2. Идеал сейчас = **голос + виджет + задачи + уведомления**. Между A и B решает дальше пайплайн.

## Ступень 2 — Декомпозиция идеала

**coreInsight:** Продукт = **скорость жеста × надёжность «не забуду вовремя»**. Всё, что не ускоряет жест и не повышает надёжность срока — лишнее.

| Компонент | × скрестить | subIdea для идеала |
|-----------|-------------|-------------------|
| Продукт | Рация / walkie-talkie | Одна кнопка. Нет чата, ленты, настроек в момент захвата |
| Аудитория | Люди «между делом» | Водители мысли, родители, селлеры, кто говорит быстрее, чем печатает |
| Механика | Секретарь + будильник | Speech → задачи с `when` → системный Reminder/пуш. Без своего «красивого» таск-UI в MVP |

**scenarios (только эти в v1):**
1. «Завтра в 11 созвон с Машей по договору» → событие/задача + уведомление за 15 мин (и/или утром).  
2. «Не забыть купить термопасту в субботу» → задача на субботу утро.  
3. «Написать Ивану акт до пятницы» → задача с дедлайном четверг вечер.

**ecosystemWith (осознанно узко):**  
iOS Shortcuts / Android виджет / позже native. Календарь ОС — опционально во v1.5.  
**Не в экосистеме v1:** привычки, стрики, папки, теги, wiki, команда, соцсеть, «ИИ-коуч».

**Матрица «оставить / выкинуть»**

| Фича | Вердикт | Почему |
|------|---------|--------|
| Виджет / одна кнопка | ✅ must | Весь смысл |
| Голос → текст | ✅ must | Вход |
| Разбор на задачи | ✅ must | Ценность |
| Дата/время из речи | ✅ must | Иначе это диктофон |
| Уведомления | ✅ must | Иначе не «не забуду» |
| Подтверждение вечером (B) | ✅ should | Ловит ошибки ИИ, поднимает доверие |
| Несколько задач из одного голосового | ✅ should | «…и ещё купи молоко» |
| Фото / OCR | ❌ v2 | Раздувает, другая ошибка |
| Share из чатов | ❌ v2 | Другой UX |
| Свои папки/проекты | ❌ never в ядре | Notion-ловушка |
| Чат с ИИ «давай подумаем» | ❌ never в ядре | Убивает простоту |
| Стрики / геймификация | ❌ never | Зеркало + лишнее |
| Красивый канбан | ❌ v1 | Система Reminders/простой список достаточно |
| Командный доступ | ❌ v1 | B2C соло сначала |

## Ступень 3 — Критик (что упустили и что убьёт)

| Поле | Атака |
|------|--------|
| systemicRisks | Apple/Google уже делают voice→reminder; Whisper+ChatGPT вручную; Shortcuts «запись → ИИ → Напоминания» соберёт гик сам; ошибка даты («в пятницу» без контекста) = потеря доверия навсегда |
| competitors | Apple Reminders+Siri, Google Assistant, Notion AI, Voice Notes + ручной разбор, TG-боты |
| regulatoryMines | голос = биометрия/ПДн; хранение аудио; удаление данных; не обещать «юр. точность» встреч |
| audienceResistance | «Siri и так умеет»; лень ставить виджет; не доверяют ИИ со сроками |
| weakestLink | **парсинг времени и имён** + **трение установки виджета** на iOS |
| threatLevel | средний (дифференциация) / высокий (если качество дат слабое) |
| fixSuggestion | 1) Всегда показывать карточку «как понял» перед финалом или вечерний чек. 2) На iOS — Shortcut на экран «Назад»/Action Button как день-1, native виджет — сразу после. 3) Явный «переспросить, если нет времени». |

**Упущенное (критик нашёл):**

1. **Нет времени в фразе** — что делать? → карточка «без срока» + спросить в вечернем разборе, не молча класть в никуда.  
2. **Одно голосовое = несколько дел** — must split.  
3. **Исправление одной кнопкой** — «не то» → перезаписать / поправить текст. Без этого churn.  
4. **Тишина / шум / обрыв** — не создавать пустых задач.  
5. **Часовой пояс и «завтра» после полуночи** — правила, не «как ИИ нафантазировал».  
6. **Повтор уведомлений** — snooze «+1 час / завтра» (минимум).  
7. **Оффлайн** — очередь: записал сейчас, разобрал когда сеть есть (иначе в метро продукт мёртв).  
8. **Приватность** — аудио можно не хранить после разбора (только текст+задача) — сильный trust-ход.

## Ступень 4 — Судья

| Заточка | feasibility | profitability | originality* | risk | recommendation |
|---------|-------------|---------------|--------------|------|----------------|
| A только голос+виджет | 70 | 65 | 60 | средний | реализовывать как ядро UX |
| B + вечерний чек | **74** | **70** | 68 | средний | **реализовывать (идеал v1)** |
| C мультивход | 62 | 68 | 55 | выше | отложить |

\*originality не в «ИИ», а в **безжалостном минимуме + надёжность срока + вечерний чек без склада**.

**verdict судьи:** Идеал = **A∪B**: виджет-голос как единственный вход v1 + обязательный лёгкий checkpoint (сразу карточка «так понял?» *или* вечерний пакет — лучше **сразу карточка на 1 тап**, вечер как опция). C не трогать, пока 30 человек не живут на голосе 2 недели.

## Ступень 5 — Банк

**selectedIdea:** VoiceCapture v1 = **виджет/кнопка → голос → задачи с уведомлениями → 1-тап подтверждение**

**rejections:**
- C мультивход — размывает MVP и бюджет ошибок (OCR ≠ ASR).  
- «Красивый свой таск-менеджер» — путь к прибыли хуже: дольше разработка, сравнение с Todoist.

**challenges:**

1. **конкуренты / Siri**  
   *team:* Siri требует точных формулировок и плохо живёт в RU-бытовом потоке. Мы: свободная речь → несколько задач → видно, как поняли → системные пуши. RU-first, простой онбординг.  
   *bank:* accepted

2. **монетизация**  
   *team:* 7 дней trial → 299–399 ₽/мес. Лимит бесплатно: N голосовых/нед. Платят за снятие тревоги «распарсит и напомнит», не за минуты ИИ.  
   *bank:* accepted

3. **дифференциация**  
   *team:* Не чат и не заметки. Метрика продукта: % голосовых, из которых пользователь **оставил** задачу с временем. Виджет как единственный hero-вход.  
   *bank:* accepted

**finalDecision: ОДОБРЕНО**  
**fundingAmount:** 0–50k ₽ на MVP (бот/PWA + Shortcuts + оплата)  
**bankVerdict:** Идеал готов к проработке. Сначала доказать цикл «голос → верная задача → уведомление сработало» на 20 пользователях; виджет native — как усиление того же цикла, не отдельный продукт.

**Путь вывода (чтобы не утонуть в App Store):**
1. Неделя 1–2: Telegram-бот voice → карточки → напоминания ботом.  
2. Параллельно: iOS Shortcut «кнопка → запись → наш API».  
3. Когда retention > порога — Android виджет / iOS native.

## Ступень 6 — Зеркало

| Поле | Оценка |
|------|--------|
| seesTruly | «Мне не нужно быть организованным человеком — мне нужен надёжный жест, после которого можно не помнить» |
| newIllusion | «Раз сказал — значит сделано» (если нет подтверждения и пуши молчат) |
| harmVector | Утечка голосовых (имена, адреса, деньги); ложное чувство контроля при кривом парсинге даты |
| vulnerableUser | Тревожный пользователь начнёт диктовать всё подряд → шум уведомлений → ещё тревога |
| compulsionRisk | средний при «записывай больше»; **низкий**, если нет стриков и есть лимит открытых задач + snooze |
| retainsWithoutClarifying | false при обязательном «так понял?» и праве удалить |
| growthEqualsBenefit | да: больше **успешных напоминаний вовремя** = больше пользы; не «больше минут аудио» |
| **verdict** | **ПРОПУЩЕНО** |
| repair | Не хранить аудио дольше разбора (по умолчанию); метрика = доставленные вовремя напоминания; антиспам: не плодить пуши без времени; кнопка «забыть» |
| mirrorVerdict | Идеал честный: рост = люди реально не забывают обещанное себе, а не слушают свой голос в архиве |

## Идеал продукта (зафиксировано)

### Одна фраза
**Зажал кнопку на виджете → сказал про дела и встречи → ИИ разложил по задачам и поставил уведомления → одним взглядом подтвердил.**

### Что есть в v1 (и только это)

```
[Виджет / кнопка]
       ↓ голос
[Распознавание]
       ↓
[ИИ: задачи + даты + (опц.) несколько дел из одного файла]
       ↓
[Карточка «Так понял?» → ОК / Править / Удалить]
       ↓
[Уведомления / Напоминания ОС]
       ↓ опционально
[Вечер: 2 минуты на хвост без срока]
```

### Чего нет в v1 (сознательно)
Фото, share, папки, теги, чат с ИИ, канбан, привычки, стрики, команда, «второй мозг», мотивация.

### Правила качества (чтобы не развалить доверие)

1. Нет времени в речи → не выдумывать; спросить или положить в «без срока».  
2. Сомнение в дате → переспросить одной фразой.  
3. Пустой/шумный файл → не создавать задачу.  
4. Оффлайн → очередь на разбор.  
5. Аудио по умолчанию удаляется после разбора.  
6. Из одного голосового можно выйти 2–5 задач.  
7. Snooze: +1 час / завтра утро.

### Для кого первым
Люди, которые уже пишут голосовые «себе в избранное» или держат дела в голове — не те, кто фанат Todoist.

## Итог пайплайна

```
Генератор: A минимальный голос | B + чек | C мультивход
     ↓
Декомп/Критик: выкинуть C; добавить оффлайн, split, snooze, «нет даты», privacy аудио
     ↓
Судья/Банк: ОДОБРЕНО → A∪B (VoiceCapture v1)
     ↓
Зеркало: ПРОПУЩЕНО (метрика = вовремя напомнил, не «записал»)
```

**К проработке берём:** VoiceCapture — виджет-голос → задачи → уведомления → 1-тап «так понял?».  
**Фаза 2 (после доказанного retention):** фото/чек, share, календарь как отдельный тип «встреча».
