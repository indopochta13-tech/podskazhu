# VoiceCapture — углублённый UX (удобно, минимум телодвижений)

Опора: виджет как у переводчика (верх = текст/чат, низ = микрофон + 1–2 действия).  
Принцип: **один жест закрывает задачу**; руками — только когда голос нельзя.

---

## 1. Карта жестов (как человек живёт)

| Ситуация | Жест | Результат |
|----------|------|-----------|
| Руки свободны, можно говорить | Виджет → **микрофон** | Голос → разбор → «записала» + время пуша |
| Метро / шум / стесняюсь | Виджет → **верхняя полоса** | Чат → текст → тот же разбор |
| Хочу глянуть / поправить | Виджет → полоса или иконка списка | Закладки → правка / отмена |
| Встреча отменилась | Голос/чат: «отмени встречу завтра на Таганке» | ИИ находит и снимает + подтверждение |
| Напомнить другому | В карточке → **Отправить** → люди/категория | Им приходит карточка + их уведомление |
| Нет сети | Голос или текст уходит в **очередь** | Разбор при сети; локально видно «ждёт отправки» |

---

## 2. Виджет (как переводчик, но наш)

```
┌─────────────────────────────────────┐
│  ✎  Написать или открыть чат     ›  │  ← верх: текст / вход в чат
├─────────────────────────────────────┤
│                                     │
│    🎤              ☰                │  ← mic = захват; список = закладки
│                                     │
└─────────────────────────────────────┘
```

**Правило кнопок:** в v1 только **2** снизу (mic + список).  
Третью (например «отправить кому-то») — **не на виджет**, а внутрь карточки задачи, иначе виджет станет пультом.

| Зона | Действие |
|------|----------|
| Верхняя полоса | Открывает чат с фокусом на клавиатуру (быстрый набор) |
| 🎤 | Hold-to-talk или tap-to-record → сразу разбор |
| ☰ | Закладки / «что записано» без чата |

Долгое нажатие на 🎤 можно позже дать «режим встречи» — не в v1.

---

## 3. Мозг: не «заметки», а команды

ИИ понимает **типы фраз**, не просто сохраняет текст.

### Создать
- «Встреча завтра в 10 на Таганке»  
  → тип: встреча · завтра 10:00 · место: Таганка · пуш за N мин (из настроек)

### Изменить
- «Перенеси встречу на Таганке на 12»  
  → находит ближайшую подходящую → меняет время → подтверждает

### Отменить
- «Отмени встречу завтра на Таганке»  
  → снимает задачу + уведомления → «отменила»

### Уточнить, если неясно
- Двух «завтра в 10» → «Какую: Таганка или созвон с Иваном?» кнопками в чате  
- Нет времени → «Без срока / спросить время» одной кнопкой

### Ответ в чате (всегда одинаковая форма)
```
✅ Записала
• Встреча · завтра 10:00 · Таганка
🔔 Напомню в 9:45
[ Изменить ] [ Отменить ] [ Будильник ] [ Отправить ]
```

Минимум телодвижений: после голоса **ничего жать не обязательно** — карточка уже стоит, пуш запланирован. Кнопки — только если нужно иначе.

---

## 4. Чат = пульт, не «болталка с ИИ»

Чат нужен для:
1. текстового ввода (шум/метро);
2. коротких ответов ИИ («записала / отменила / не нашла»);
3. кнопок под карточкой.

Чат **не** для длинных рассуждений. Нет ленты советов. История = лента действий (создал / изменил / отменил).

**Будильник на задачу**  
Отдельная кнопка на карточке: ставит системный alarm/громкий пуш на время события (сильнее обычного notification) — для «не проспать встречу».  
В настройках: «по умолчанию будильник для встреч: вкл/выкл» и за сколько минут.

---

## 5. Закладки (полки) — что смотреть руками

Не папки Notion. **4 полки максимум** в v1:

| Закладка | Что внутри | Зачем |
|----------|------------|-------|
| **Сегодня** | Всё на сегодня по времени | Главный экран после виджета-списка |
| **Встречи** | События с местом/временем | Быстро отменить/перенести |
| **Дела** | Задачи без «событийности» | Купить / написать / сделать |
| **Дни рождения** | Дата → ежегодное напоминание | Отдельный спокойный сценарий |

Позже (не в v1): Дом / Работа как **фильтр людей и меток**, не отдельные тяжёлые миры.

**Ручное изменение в закладках (метро, без голоса):**
- тап по карточке → время / дата / название / место  
- свайп или кнопка → отменить  
- то же доступно из чата кнопками  

Один и тот же объект везде: чат, закладка, уведомление.

---

## 6. Дни рождения (отдельный простой сценарий)

- «День рождения Маши 12 марта» → полка ДР + напоминание заранее (настройка: за 1 день / утром в день)  
- Вручную: закладка → добавить имя + дату  
- Не смешивать с обычными встречами в ленте «Сегодня», кроме дня когда пуш уже нужен  

---

## 7. «Отправить другому» (рассылка себе подобным)

Это мощно, но легко расползтись. Режем до простого клина.

### Как работает для отправителя
1. Есть задача/встреча.  
2. Жмёт **Отправить**.  
3. Выбор:  
   - люди (чекбоксы из записной книжки приложения);  
   - или категория **Работа** / **Дом** (пресеты списка людей из настроек).  
4. Уходит карточка: заголовок, время, опционально текст «собрание в 10».

### Как у получателя
- Пуш / глубокая ссылка: «Валерий напоминает: встреча завтра 10:00»  
- Кнопки: **Принять в мои напоминания** / Отклонить  
- Принять = задача появилась **у него** + **его** уведомление (не зависит от отправителя дальше)

### Что в настройках заранее
- Список людей (имя + телефон/Telegram/@/ссылка-приглашение)  
- Пресеты: Работа = [коллеги], Дом = [семья]  
- Можно сказать ИИ: «добавь в работу коллегу Сашу» → он внесёт в пресет (с подтверждением)

### Чего нет в v1
- Групповой чат, статусы «прочитал», комментарии, голосовые всем  
- Только: карточка-напоминание + принять/отклонить  

**Старт проще:** сначала шаринг ссылкой (даже без приложения у друга → веб-страница «добавить в календарь/напоминания»). Приложение у друга — v1.5.

---

## 8. Оффлайн и шум (обязательные правила)

| Случай | Поведение |
|--------|-----------|
| Нет сети, голос | Запись локально → очередь → разбор при сети → пуш «разобрала 2 из очереди» |
| Нет сети, текст | То же: очередь сообщений |
| Шум / ИИ не уверен | «Не расслышала, напиши текстом?» + открыть чат |
| Частичный разбор | Показать черновик с жёлтой пометкой «проверь время» |

---

## 9. Настройки (один раз настроил — дальше жесты)

Короткий экран, без зоопарка:

1. **Напоминать заранее** — для встреч: 15 / 30 / 60 мин (дефолт 15).  
2. **Будильник для встреч** — вкл/выкл + за сколько.  
3. **Вечерний разбор** — время пуша «хвост без срока» или выкл.  
4. **Люди** — список + пресеты Работа / Дом.  
5. **Тихие часы** — не пушить ночью (кроме будильника встреч, если включён).  
6. **Ежедневные якоря** (опционально) — 1–3 повторяемых дела («таблетки 21:00», «созвон стендап пн–пт 10:00»), чтобы не диктовать одно и то же.  
7. **Приватность** — удалять аудио после разбора (по умолчанию да).

«Основные задачи на каждый день» = пункт 6, не отдельное приложение привычек.

---

## 10. Что must / later (чтобы не утонуть)

### Must — v1 (удобное ядро)
- Виджет: верх = чат/текст, 🎤, ☰ закладки  
- Голос + текст → создать / изменить / отменить  
- Ответ в чате единым шаблоном + время пуша  
- Полки: Сегодня · Встречи · Дела · ДР  
- Ручная правка времени/отмена  
- Очередь оффлайн  
- Настройки: заранее / будильник встреч / люди (хотя бы список)  

### Should — v1.1
- Отправить карточку другому (ссылка + принять)  
- Пресеты Работа / Дом  
- Snooze с пуша (+1ч / завтра)  

### Later — v2
- Фото/чеки  
- Полноценное «приложение у друга» с аккаунтами  
- Календарь ОС двухсторонняя синхронизация  
- Третья кнопка на виджете

## 11. Минимальный пользовательский сценарий дня (идеал)

1. Утро: виджет 🎤 «сегодня созвон в 12 с клиентом, купить провод» → две карточки, два пуша.  
2. Метро: верх виджета → текстом «перенеси созвон на 13» → готово.  
3. Отмена: 🎤 «отмени покупку провода» → снято.  
4. ДР: раз в месяц глянул полку / или голосом добавил.  
5. Коллегам: в карточке встречи → Отправить → Работа → они приняли.  

Телодвижений сверх жеста — ноль, пока всё ок. Руки — только когда голос нельзя или нужно ткнуть дату.

---

## 12. Риски удобства (держать в голове при проработке)

1. Слишком умная отмена («отмени встречу») при двух встречах → всегда уточнять кнопками.  
2. Рассылка людям раньше ядра → не начинать продукт с «соцсети».  
3. Много полок → вернуть к 4.  
4. Чат превратится в ChatGPT → жёсткий шаблон ответов.  

---

## Зафиксированная формула

> **Виджет = микрофон + строка текста + полки.**  
> **ИИ = секретарь команд (создать / перенести / отменить), не собеседник.**  
> **Людям = карточка-напоминание из задачи, не чат компании.**
